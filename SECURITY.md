# Security Policy

StockPulse handles retail, inventory and payment-related data. We take security reports seriously.

## Reporting a vulnerability
Do not open a public issue for security problems. Report privately to: **[security contact email - to be set by Mart Code International Technologies Limited]**.

Include: description, affected component, steps to reproduce, and potential impact. Please do not access, modify or exfiltrate data belonging to other users or tenants while testing.

## Response targets (to be confirmed)
Acknowledgement and triage timelines will be defined before the first production release.

## Scope notes
- Tenant isolation, authentication, authorization, payment callbacks and offline synchronisation are priority areas.
- Never include real credentials, card data or customer data in reports or commits.

## Supported versions
No released versions yet.

A fuller `docs/SECURITY_POLICY.md` (controls and architecture) is produced during Phase 1 and Phase 10.
